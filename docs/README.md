# Documentación del Proyecto PLI

Este directorio centraliza la documentación técnica y funcional.

- Lee primero `pantallas.md` para entender cada página y sus componentes.
- `i18n.md` explica cómo funcionan las traducciones en cliente y servidor.
- `arquitectura.md` describe la estructura de carpetas y conexiones entre módulos.
- `roadmap.md` lista optimizaciones futuras y un checklist de QA.

Sugerencia: mantener esta carpeta versionada y actualizarla cuando se agreguen pantallas o se internacionalicen nuevas secciones.
